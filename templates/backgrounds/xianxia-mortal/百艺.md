# 丹药

## 定义

丹药＝灵药／灵材经火候炼成的可服消耗品；服后留**丹毒**，须闭关炼化排出。

### 【硬】通例与破境用药

- 丹毒淤堵经脉、加重破境；低阶滥服常死于丹毒反噬。
- 同种丹药久服药效递减。药力只能补积累，不能吃出下一境。
- 凡人高灵丹药虚不受补。无渡劫丹免劫。
- **跨阶服丹**（如炼气服筑基／金丹期的增益丹、疗伤丹）会因药力太猛爆体而亡。**破境丹例外**：筑基丹本就是炼气冲筑基时服的，按关口服，不算跨阶。

| 关口 | 通名 | 口径 |
|---|---|---|
| 炼气→筑基 | **筑基丹** | 伪灵根／外门几乎刚需；天／异优先配额 |
| （辅）品质 | **补天丹** | 精炼灵根品质；不减属性数、不洗成天根 |
| 筑基→金丹 | **结丹灵药** | 苛刻、非常货；非有丹必成 |
| 金丹→元婴 | **凝婴灵液**＋**定神香** | 稳神固本，不免雷劫 |
| 元婴→化神 | **化神级灵材** | 极稀；不靠量产丹 |

### 【硬】丹药抗性（数量级）

设当前大境圆满基础值为 M，修士现有基础值为 B，某丹标称增量比例为 p，第 n 颗完全炼化后的增量：

> ΔFₙ = p × M × (1−p)^(n−1)

第 1～n 颗的累计增量 **ΔF = M × (1 − (1−p)ⁿ)**，收敛到 M。但真正能转为修为的**不得超过 M − B**：越过本境圆满的部分不再长修为，转为**丹毒**淤积（重则爆体）。所以吃满的极限是 **B + ΔF ≤ M**，**不能**吃出下一境。跨阶服丹爆体（破境丹按关口服，见上）。

筑基丹抽象例（不绑定逐层炼气；M＝1，已有积累 B＝0.2，p＝0.2）：第 1 颗 +0.200→累计 0.400；第 3 颗后累计约 0.688；第 7 颗后累计约 0.990，再吃只增丹毒。药力不能替代法力液化和筑基形态蜕变。

## 硬禁则

- 勿写丹药替代心魔或跳过本境大圆满破大境。
- 勿写一颗丹免雷劫。
- 勿写跨阶吞增益／疗伤丹无事（破境丹按关口服），或同种丹无限吃出下一境——越过本境圆满的药力只会淤成丹毒。

# 法宝

## 定义

器物通名四级：**法器 → 法宝 → 灵宝 → 通天灵宝**。

**【硬】**：普通高阶法宝不需要器灵；真器灵百年难遇。

### 【硬】品级分层

| 通名 | 谁常用 | 是什么 |
|---|---|---|
| **法器** | 炼气～筑基 | 注灵成形、能催动；飞剑、储物袋等坊市通货 |
| **法宝** | 筑基高阶～金丹 | 须祭炼认主才稳 |
| **灵宝** | 金丹～元婴 | 镇库／奇遇级；才可能孕生器灵 |
| **通天灵宝** | 化神级传闻 | 传说档；非坊市通货 |

- 认主：滴血祭炼、神识烙印。捡到≠能用。
- 金丹以上普遍祭炼**一件**本命法宝；伤本命≈伤自身积累。
- 同档仍有下品／中品／上品。境界≠自动配器。
- 法力**无明显带宽**：低阶修士的法力可被高阶法器瞬间抽空。神识才有带宽限制（见神魂）。

## 硬禁则

- 勿写普通法宝量产自带真器灵。
- 勿写低阶单靠奇遇法宝正面碾压高一大境界。

# 符箓

## 定义

符箓＝把一道可激发的法术效果预先封进纸、帛、玉片，催动即发、发完即尽。通行三档：**低阶符 → 中阶符 → 高阶符**（不与器物的法器／法宝／灵宝档名混用）。

**【硬】**：制符注灵是修士专属。凡人可制版、刻纹、铺纸，不能注灵，不能靠印板独立制造法术。

### 【硬】品级分层

| 通名 | 谁催得稳 | 是什么 |
|---|---|---|
| **低阶符** | 炼气为主 | 一次性符；坊市通货 |
| **中阶符** | 筑基以上 | 真元／神识门槛更高 |
| **高阶符** | 金丹以上 | 贵重、难制；低阶持有＝烫手 |

符是消耗品；阵是占位、供灵、可维护的空间规则。一符不成护山大阵。

## 硬禁则

- 勿写会撕符催动＝会画符注灵。
- 勿写凡人独立注灵成符。

# 阵法

## 定义

阵法＝借阵基、阵眼、阵旗、阵纹把灵力约束成可复用的空间规则；禁制＝落在器物、玉简、洞府或人身的锁／印／限。破阵靠推演阵纹、寻阵眼、断供灵——不靠蛮力硬撞护山大阵。

### 【硬】构件与禁制

| 构件 | 管什么 |
|---|---|
| 阵基 | 落地承纹、与地气／灵脉接口 |
| 阵眼 | 调度与权限核心；常须修士亲为祭炼 |
| 阵旗／阵盘 | 便携节点、临时扩阵 |
| 供灵 | 灵石／灵脉／人灌；断供＝阵力骤降 |

禁制常见简易／中级／高级／秘禁四档。护山大阵吃灵脉＋存石，兼管**隔绝气机**（挡灵压，见仙凡有别卡）；日常多半开警戒，不全开杀阵。

**【硬】**：传送阵是**定点**阵法：单座跨距有限、耗石惊人，长途靠多座**接驳**成商路；**不**直达跨界。

## 硬禁则

- 勿写蛮力正面撞穿大宗护山大阵而无代价。
- 勿写传送阵当跨界按钮。

# 御器

## 定义

御器与遁术＝修士个人位移与短距逃命。单体遁速非定值：有巡航／加速／逃命之分。

### 【硬】谁飞、怎么飞

| 手段 | 常见门槛 | 能干什么 |
|---|---|---|
| **御器飞行** | 筑基起（短距）；器要认主 | 赶路、追逃、战场位移 |
| **御空飞行** | 金丹起更稳 | 较长途个人飞行 |
| **遁术** | 功法或秘术 | 短距逃命；事后补灵／伤经 |
| **传送阵** | 阵基、供能、钥印 | 定点；不跨界 |
| **飞舟／海船** | 班期、护卫、灵石 | 货运与同伴；个人遁速替不了船期 |

**【硬】**：不写炼气御剑环球。个人遁速不能替后勤缩短货运与同伴时间。

### 【硬】遁速相对系数（不是 m/s）

遁速与法力值的**根号**成正相关：遁速 ≈ 系数 × √法力。系数只校准巡航／逃命相对倍率；正文仍用「一息出城／半日越州」，**禁止**写出精确米每秒。

| 飞行状态 | 系数约值 |
|---|---|
| 轻松 | ~5 |
| 巡航 | ~10 |
| 御器加速 | 15–20 |
| 逃命秘术 | 20–30 |
| 特殊遁法 | 40–50 |

特殊遁法（含雷属性等）短距可翻数十倍，接近瞬移读感，事后仍须补灵／伤经，且**只放大短时速度、不改变航程与耐力**。

**读感锚点**（按巡航估，只作尺子）：筑基期御器日行数百里；金丹期御空日行数千里；元婴期日行万里以上。

## 硬禁则

- 勿写精确 m/s；用「一息出城／半日越州」等读感。
- 勿写遁术／传送阵直达跨界。

# 叙事时间

## 定义

章内「一息／一炷香／半日」等口头时间的换算尺子。只校准读感，不必每句都换算成秒。

### 【硬】时间尺度换算

| 时间跨度 | 换算 |
|---|---|
| 一瞬 | 0.1–0.3 秒 |
| 一息 | 1.5–2 秒 |
| 一袋烟 | 5 分钟 |
| 一盏茶 | 10 分钟 |
| 一炷香（亦称一柱香） | 30 分钟 |
| 一顿饭 | 30–60 分钟 |
| 一个时辰 | 2 小时 |
| 小半日 | 3–4 小时 |
| 半日 | ~6 小时 |
| 大半日 | 8–10 小时 |
| 一日（白天） | 12 小时 |
| 一夜 | 12 小时 |
| 一日一夜 | 24 小时 |

## 硬禁则

- 勿把上表写成不可通融的物理钟；对话里用口头单位即可。
