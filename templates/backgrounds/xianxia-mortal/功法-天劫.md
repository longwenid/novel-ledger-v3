# 天劫与破境雷劫

## 定义

两套分轨外劫：

1. **破境雷劫／天劫**：冲大境当次的天地外劫。
2. **周期个人小天劫**：化神稳固后约数百年一轮的本人劫期；不是破境雷劫本身。

二者皆不是心魔。

### 【硬】破境雷劫（锁死）

| 关口 | 雷劫／天劫？ | 写法要点 |
|---|---|---|
| 炼气→筑基 | **无** | 主险＝灵力液化、灵根与筑基丹 |
| 筑基→金丹 | **无** | 主险＝结丹灵材＋心魔／走火；无天地异象 |
| 金丹→元婴 | **必有（结婴雷劫）** | 假婴→碎丹结婴；失败高死；心魔可同场、分轨叙述 |
| 元婴→化神 | **必有（冲化神天劫）** | 凡人冲化神必渡外劫 |
| 化神→炼虚及更高 | **人界无路** | 人界灵气不足以续修，须飞升更高界；勿写本界成功成例 |
| 大乘→渡劫（晋仙） | 必有外劫 | 更高界关口；与结婴雷劫分轨 |

- 勉强度过常折寿显老；安然渡过亦有消耗。勿写越渡越年轻／无损耗。
- 无「一颗渡劫丹免劫」。丹药只稳神固本，不取消劫。

### 【硬】周期个人小天劫

- 仅化神及以上。元婴及以下无周期性个人小天劫。
- 自化神**稳固后**起算，不是入化神当日。本库取约**三百年**一轮（写「近三百年／劫期将至」即可）。
- **同境内劫威不递增**：化神期每轮劫威相当，靠底子硬扛；跨大境才显著增强。死因是「越渡越伤、总有撑不住的一轮」，不是每轮都更难。
- 炼虚期（更高界）小天劫仍按三百年时钟，劫威较化神显著增强、折寿风险更大；不另立更长周期替代。
- 跌境只暂缓到期之劫、不注销；重返化神后十年内须补渡。

## 硬禁则

- 勿写人界结婴无雷劫，或冲化神「可有」天劫。
- 勿写炼气／筑基／结丹有破境雷劫。
- 勿写心魔＝雷劫，或捆成同一次必经事件。
- 勿写渡劫返老／无损耗，或丹药／秘术永久免劫。
- 勿写人界化神之上自行破境：那是飞升更高界之后的事，不是人界的破境雷劫。

# 功法

## 定义

功法＝可复用的修行说明书：怎么引气、温养、破关、何时停手、失败怎么收。购买抄本只得文字与图谱，得不到原主的灵地、药材、师长与失败经验。

### 【硬】一门功法的构成

| 部件 | 管什么 | 缺了会怎样 |
|---|---|---|
| 总诀 | 属性取向、主修窍位、境界上限 | 错属、硬修相克 |
| 行气 | 周天与分行方向、节拍 | 滞涩、走火前兆 |
| 温养 | 日常吐纳、归元 | 进境虚 |
| 破关 | 小境／大境冲关要点与护持 | 卡在九层圆满或本境圆满空转 |
| 停手征兆 | 何时必须断功 | 不知停＝硬冲 |
| 失败处置 | 断功、化毒、再启条件 | 抄本最常缺这一块 |

### 【硬】授受档

| 档 | 常见范围 | 读感 |
|---|---|---|
| 外门／通识 | 炼气～筑基入门；多缺破关／失败处置 | 有石买得到外门货 |
| 内门 | 完整至筑基或金丹前 | 门里正经书 |
| 真传 | 金丹主修向；口授＋禁制 | 听过名字也碰不到 |
| 镇宗 | 元婴向根本 | 镇山的那本 |
| 家族秘传 | 多止金丹完整；元婴级极稀 | 不外传 |

**【硬】**：玉简常有禁制（限阅览、禁传抄、认主／血脉印）。私传或强破＝反噬、功法自毁、门规追责。改法不能跳过九层圆满、心魔或免结婴雷劫／冲化神天劫。

## 硬禁则

- 勿写抄本／残篇＝完整真传。
- 勿写无代价破解镇宗玉简后安然无事。
- 勿写改法替代心魔或免雷劫。
