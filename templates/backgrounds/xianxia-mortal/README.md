# 预选背景：修仙基础（xianxia-mortal）

人界公开基础设定库。可选用，不绑定任何一部书的专有宇宙。

## 锁死选择（必须先读）

| 项 | 本库选择 | 说明 |
|---|---|---|
| 灵压口径 | **气机压迫（灵压）** | 只压活物神魂气血，不做引力／质能密度一类现代物理嫁接 |
| 炼气层数 | **九层**（九层圆满后方可冲筑基） | 常见公开写法亦有十三层。本库不写十三层制。 |
| 结丹 vs 金丹 | **大境称「金丹」**；破境手续称「结丹」 | 不另立「结丹期」与「金丹期」两套阶梯。 |

## 通过开书选择装入

在确认后的 `novel-ledger.hatch.v3` manifest 顶层记录：

```json
{
  "schema": "novel-ledger.hatch.v3",
  "background": "xianxia-mortal"
}
```

其余 v3 必填决策照常提供。`book hatch` 会在同一次启动中把本目录的正典卡装入
`$PROJECT/book/kb/canon/` 并编译 `cards.json`；README 本身不会进入项目正典。

已有项目若要人工采用，可把本目录中除 README 外的 md 拷进 `$PROJECT/book/kb/canon/`，再执行 `kb sync`。

## 收录范围

只收对照人界公开基础后判定为「符合」或「口径不同但可用」的硬表：境界与寿元、进阶阈值与小境占比、灵根与五行生克、灵石品阶与换率、功法授受、丹药抗性、法宝、符箓、阵法、御器遁速系数、叙事时间换算、神识带宽／观察修为、储物、夺舍、破境雷劫、仙凡有别（灵压／收敛门槛／仙凡两界）、妖兽等阶与灵脉品阶。

**不收**：大道螺旋、仙凡双轨制度专篇、九宗名片、收割者／牧场宇宙，以及任何小说原文摘抄。
