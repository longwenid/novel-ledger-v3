# 仙凡有别：灵压与两界之隔

## 【硬】总因

修士与凡人隔三道：**灵根**（无灵根不能引气，见境界卡）、**寿元**（凡人天年六十至百，修士逐境抬升，见境界卡）、**灵压**（灵力越厚，外溢的气机越重）。前两道决定能不能修，第三道决定能不能同处。

因果锁死：**境界↑ → 灵力越厚 → 外放灵压越重 → 凡人／低阶修士近之不适**。灵压是**灵力外溢的气机压迫**，不是物理质量、引力，也不做现代物理嫁接。

**分档**：炼气、筑基灵压微弱，在凡间**不收敛也无碍**；**金丹**是收敛门槛——金丹及以上入凡，先自行收敛（见【三】）。

## 【硬】一、灵压是什么

- **灵压＝灵力外溢**，不是主动施法。修士每时每刻都在溢，只是强弱不同；**收敛**（敛息、锁息）是把外溢的气机压回体内。
- **只压活物，不推死物**：灵压压迫神魂与气血，人、兽、修士才受制；墙不倒、光不弯、地下水不改道。毁物伤人要靠术法，不靠站在那儿。
- **同境越深越重**：同一大境内，初期与圆满的灵压有别；跨大境才是数量级的差别。

| 外放者 | 凡人读感 | 低阶修士读感 |
|---|---|---|
| 炼气 | 无感，至多觉其精气神足 | 同阶可辨强弱 |
| 筑基 | 不怒自威，不敢直视 | 炼气者气息一滞 |
| 金丹 | 近身胸闷气短、腿软心悸 | 炼气者如负山，言语不畅 |
| 元婴 | 百丈内瘫软跪伏，久压昏死 | 筑基者神识刺痛 |
| 化神 | 十里内气息不畅，百丈内可令凡人气绝 | 金丹者元婴不稳 |

**口径**：灵压**不替代杀伐**。远距离只让人不适，贴身才可能致命；真打起来仍看术法与法宝（见【四】）。

## 【硬】二、收灵压与藏修为是两件事

- **收灵压（敛息）**：把外溢气机压回体内，凡人见之如常人。**金丹起**入凡的前提。
- **藏修为（掩息、匿踪、易容）**：让别的修士看不出你的境界，属秘术／法宝范畴。
- 两者**互不替代**：收灵压不等于藏修为。都做到，才是「凡人眼里是凡人，修士眼里也是凡人」。

## 【硬】三、境界分档：谁必须收敛

分档按**大境**切，不按功法或资质另开表：

| 境界 | 灵压外溢 | 入凡是否必须收敛 |
|---|---|---|
| 炼气／筑基 | 微弱，凡人至多觉得气势足 | **不需要**：混居凡间是常态 |
| 金丹 | 近身可令凡人胸闷腿软 | **需要**：金丹起入凡先收敛；压得住、代价小，可长期维持 |
| 元婴 | 百丈内凡人瘫软，久压昏死 | **必须**：收敛转持续功夫、耗真元、破功回弹 |
| 化神 | 十里内凡人气息不畅 | **必须**：每降一档灵压真元耗费指数级上升；本界开篇不作日常 |

**口径**：门槛定在**金丹**——金丹一成，精元内敛、灵力由量变入质变（见境界卡），灵压外溢开始被凡体感知。炼气、筑基不收敛**不算破禁**；金丹及以上不收敛的下场见【四】。

## 【硬】四、按距离递减（凡人视角 · 金丹以上外放）

同一境界越近越重，同一距离境界越高越重。下表只作读感尺子，勿换算成精确米数（百丈约一里，十里约五公里量级）：

| 距离 | 金丹 | 元婴 | 化神 |
|---|---|---|---|
| 十里之外 | 无感 | 心悸、无端生畏 | 胸闷、气息不畅 |
| 百丈之内 | 稍感不适 | 瘫软跪伏，久则昏死 | 吐血昏厥，可致命 |
| 十丈之内 | 胸闷腿软，神志尚清 | 昏死，久压可致命 | 当场气绝 |
| 贴身 | 气血翻涌，可伤根基 | 当场气绝 | 气绝且伤及神魂 |

**口径**：灵压压迫**不需动手**，但不能写成隔空千里取命；「气绝」只发生在贴身，且死于灵压压迫而非术法杀伐。金丹以上一旦全力施为（斗法、渡劫、破功回弹），灵压按上表在近距离重演。

## 【硬】五、气机收敛：修士如何下凡（以及为什么待不久）

金丹及以上并非只能困在洞府——**主动收敛**（气机内敛、锁息、敛息术一类）可以把外溢灵压压回体内，使凡人与低阶修士都觉不出异常，从而**能以凡人面目行走凡间**。但这条通道有两条硬约束：

- **收敛是持续的功夫，不是一次性的开关**。它要求修士主动压制自身灵压，**境界越高越难压**（化神之上每降一档灵压，耗费的真元都指数级上升）。收敛期间不能斗法、不能动用大法力：一旦破功（神识受创、情绪失守、被迫全力施为），被压住的灵压会**瞬间回弹**，【四】表里的效应按距离一次性重演——对近处的凡人而言，等同于当场行刑。
- **凡间灵气驳杂，久留无益且亏本**。凡人世界的天地灵气稀薄、驳杂不纯：修士在此**无法有效补充真元**，而收敛本身就在持续消耗；于是停留是**净亏损**。短则数日、长则旬月，资质差或境界低的会明显掉状态，故一般**不会久待**，事毕即走。这也解释了为什么高阶修士宁可在洞天福地闭关，也不愿在凡间盘桓——不是因为不能，而是因为**不划算**。

**口径**：本条只解释金丹及以上「为何能下凡、又为何不常驻」，**不新增战力规则**（收敛期间战力按真实境界打折、而非按凡人算），**不改**寿元数字与灵石品阶表。

## 【硬】六、仙凡两界之隔

- **凡人不识修士**：收灵压后，修士在凡人眼里与常人无异；凡人**看不出**谁在修行，能看修为的只有修士（见神魂卡）。
- **修士不涉凡俗**：各宗有默契——不插手凡俗王朝、不在凡人聚居地斗法、不显法于市井。破例者断的是自己的财路与名声。
- **宗门要挡灵压**：护山大阵兼管隔绝气机；金丹以上开坛、闭关、斗法都在阵内，免得自家人先被自家人压垮。
- **飞升**：人界化神为顶，再往上须飞升更高界（见境界卡）；本库不展开更高界地图。

## 硬禁则

- 凡间戏**勿**把金丹及以上修士写成看起来和凡人一样轻飘无害、挤在凡市里毫无异状——能这样走动的，一定是**正在收敛**且付着真元代价的，不是本来就没灵压。
- **勿把低境修士写成行走的灾祸**：炼气、筑基灵压微弱，不收敛混迹凡间是常态；反过来，也勿要求他们时刻敛息。
- **勿把收敛写成免费**：门槛自**金丹**起，持续耗真元、境界越高越难压；破功即瞬间回弹，且不能让破功的场面「雷声大雨点小」。
- 勿把【四】的距离效应安到炼气、筑基头上：低境修士走近凡人也压不出胸闷与昏死。
- **勿把灵压写成现代物理**：不写引力、质能密度、黑洞、时间膨胀、引力波一类效应；灵压只压活物神魂气血，不推墙、不弯光、不改地质。
- **勿让修士久居凡间还越住越强**：凡间灵气驳杂无法补真元，久留是净亏损，事毕即走才符合设定。
- **勿写高阶斗法无后果**：金丹以上在凡人聚居地全力出手，近处凡人非死即伤，须避开人烟、入阵或另择战场。
- 「仙人威压／仙音渺渺／朝圣跪拜」按上文物理解释写，**不要只当修辞**。
