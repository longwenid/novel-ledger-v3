# 创意编辑 · 高级推演模式细则

按需引用文档。总编辑在派发 prompt 中点名授权某个模式时，创意编辑才读取本文件。
三个模式都**遵守主卡的收口契约与禁区**：产出是决策证据，不直接写入正式真源。

启用流程：

1. 总编辑在派发创意编辑时明确授权模式（如“使用跨题材融合推演”）；
2. 创意编辑按对应模式推演，仍受收口契约约束；
3. 输出候选方案后，由作者/总编辑按 [决策权矩阵](../../references/roles.md) 拍板；
4. 若采纳“反宪法推演”的极端设定，新宪法写入项目 `intent.md` 替代默认宪法。

本文件只给**方法与模板**，不携带任何一部作品的世界观、人物或文风；
所有示例一律用占位符（`题材A` / `题材B` / `痛点X`），推演时替换为本项目真源。

---

## 一、反宪法推演（Heretical Brainstorm）

**适用场景**：开新书（0→1 孵化），探索元叙事 / 荒诞 / 实验性题材。风险等级：高。

**核心理念**：暂时放宽《全书编辑总宪法》的常规约束，推演突破第四面墙、认知视界崩塌
或无守恒的极端设定，然后为这些设定**建立一套新宪法**——越界必须配新规则，不是无约束。

**推演流程**：

1. **越界脑暴**（仅此阶段放宽常规约束）
   可探索的极端类型（每一类都要能回答“长线怎么办”）：
   - **元叙事**：角色意识到自己身处叙事之中；
   - **认知崩塌**：世界观在中途被彻底颠覆；
   - **无守恒荒诞**：因果律失效、逻辑悖论世界；
   - **反沉浸实验**：叙事与接受者直接对话、作者介入故事。
2. **新宪法构建**：回答“若要做成长篇，这个极端设定需要什么新规则”，三个必答项：
   - **底线在哪**：哪些规则仍然必须守恒（角色动机、基本因果）；
   - **新的张力源**：打破常规宪法后，紧张感从哪里来；
   - **长篇可持续性**：该设定能支撑多长篇幅而不失控，失控点在哪。
3. **候选方案收敛**：输出 2~3 个极端设定草案，每个附新宪法草案与风险评估
   （实验性强度、读者接受度、执行难度）。

**决策点**：作者选择是否采纳。采纳 → 新宪法替代默认宪法写入 `intent.md`；
不采纳 → 回到守恒律推演模式。

**泛化模板**：

```markdown
【输入】<作者的原始点子>

【反宪法推演】

极端设定 A：【<设定名>】
- 核心：<一句话核心机制>
- 打破的常规条款：<宪法第几条 / 哪条守恒律>
- 新宪法：
  * 守恒：<新规则下的资源与代价是什么>
  * 张力源：<紧张感从何而来>
  * 底线：<角色动机与基本因果如何保住>
- 风险：<实验性强度 / 读者接受度 / 执行难度>

极端设定 B：【<设定名>】 …（同上）
极端设定 C：【<设定名>】 …（同上）

【收口】
推荐：<设定 X>；理由：<张力是否清晰 / 是否可逐步揭示 / 执行难度>；
建议揭示节奏：<开篇即 meta / 中段揭示 / 逐卷递进>。
```

## 二、跨题材融合推演（Genre Fusion）

**适用场景**：开新书、跨卷设计，寻找差异化切入点。风险等级：中。

**核心理念**：用一个题材的规则**约束**另一个题材，在冲突点找到创新空间。
融合不是叠 buff，是让两套代价互相咬合。

**推演流程**：

1. **识别题材核心张力**：分别列出两个题材各自的“最强张力点”
   （按本项目题材取用，例如技术代价 / 江湖义气 / 未知恐惧 / 逻辑还原 / 资源与生存焦虑）。
2. **设定约束机制**：确定“用题材 A 的规则约束题材 B”的方式，
   形如「<题材A规则> 使 <题材B的常态> 必须付出 <代价>」。
3. **守恒律重构**：逐条写清
   - 各题材原有代价**都保留**（融合不等于无敌）；
   - 冲突点成为张力源（越常用能力，越触发另一套规则的惩罚）。
4. **候选方案收敛**：输出 2~3 个融合设定，每个附核心冲突、守恒律与差异化卖点
   （与已有作品的区别）。

**泛化模板**：

```markdown
【输入】融合：<题材A> + <题材B>

【跨题材融合推演】

## 融合设定：【<设定名>】

### 题材A张力
- 核心：<张力点>
- 常见缺口：<该题材大多数作品没解决的博弈问题>

### 题材B张力
- 核心：<张力点>
- 常见缺口：<同上>

### 融合机制：【<机制名>】
世界规则：
- <把题材A的抽象规则变成可对抗的实体>
- <由此派生的社会制度 / 职业 / 权力结构>
- <主角的切入点为何成立>

### 守恒律重构
1. 题材A守恒（保留）：<原有代价如何继续生效>
2. 题材B守恒（保留）：<原有代价如何继续生效>
3. 融合新增守恒：<新规则自身的成本、上限与不可逆性>

### 核心冲突设计
- <规则 vs 正义 / 代价 vs 目标 / 顶层 vs 底层，三选二以上>

### 差异化卖点
- <与“纯粹的A”“纯粹的B”“A+B叠buff”分别的区别>

### 第一卷卷脊候选
候选A：<案件 / 事件名> —— 案件、真相、高潮
候选B：<案件 / 事件名> —— 同上
```

## 三、商业化倒推（Audience-First Design）

**适用场景**：开新书，商业目标明确。风险等级：低。

**核心理念**：从目标受众的痛点/爽点倒推设定，而不是“先有设定再找读者”。

**推演流程**：

1. **受众画像拆解**：年龄/性别/职业（代入感锚点）、核心痛点（现实中缺什么）、
   消费习惯（爽点密度 vs 深度沉浸）、题材偏好（避开什么、喜欢什么）。
2. **爽点/痛点映射**：把受众痛点映射为主角的处境与反击方式
   （痛点 X → 爽点 Y，且 Y 的代价由守恒律承担）。
3. **节奏设计**：明确爽点密度与付费节奏
   - 短篇节奏与长篇节奏分开给（每 N 章一次小爽、每卷一次大爽）；
   - 章末悬念落在付费点前的最后一段。
4. **候选方案收敛**：设定方案（主角/金手指/世界观）+ 爽点节奏表（前 10 章分布）
   + 付费转化设计（免费章吸引点 + 付费章爆点）。

**泛化模板**：

```markdown
【输入】
- 目标受众：<年龄段 / 性别 / 职业 / 阅读场景>
- 商业目标：<点击率 / 留存 / 付费率，按优先级>

【商业化倒推推演】

## 一、受众痛点拆解
核心痛点：1) <痛点1> 2) <痛点2> 3) <痛点3>
爽点需求：1) <爽点1> 2) <爽点2> 3) <爽点3>
题材偏好：✅ <接受> ✗ <排斥>

## 二、设定倒推
### 主角设定
姓名 / 年龄 / 职业：<…>；现状：<…>；性格：<缺陷也要写清>
### 金手指
来源：<…>；能力：<…>
代价（关键）：<…>
守恒闭环：<为什么不能无限开挂 → 如何自然制造冲突 → 后期危机是什么>
### 世界观
<统治性规则 / 阶层结构 / 主角的生态位>

## 三、爽点节奏设计（前 10 章）
| 章节 | 剧情 | 爽点类型 | 付费设计 |
|---|---|---|---|
| 1 | <…> | 痛点铺垫 | <免费 / 付费 + 章末钩子> |
| … | | | |

## 四、付费转化设计
- 免费章策略：<建立代入感 / 展示金手指 / 埋悬念 分别安排在哪几章>
- 付费章爆点：<哪几章留人、哪几章升级危机>
- 章末挖坑公式：<爽章结尾埋什么、危机章结尾埋什么>

## 五、差异化卖点
<与同类作品三条以上可验证的区别>

## 六、风险与应对
- 风险：<题材天花板 / 元素劝退 / 长线乏力>
- 应对：<前几章强化哪一项 / 哪些元素软化 / 中后期如何扩格局>
```

## 四、模式选择速查

| 模式 | 启用时机 | 适合题材 | 风险等级 | 必须收口 |
|---|---|---|---|---|
| 反宪法推演 | 开新书（实验性题材） | 元叙事、荒诞、实验文学 | ⚠️⚠️⚠️ 高 | 新宪法草案 |
| 跨题材融合 | 开新书、跨卷设计 | 任何题材组合 | ⚠️⚠️ 中 | 融合设定 + 守恒律 |
| 商业化倒推 | 开新书（商业目标明确） | 都市、职场、轻小说 | ⚠️ 低 | 设定 + 爽点节奏表 |

两条纪律：

- 高级模式仍有约束，必须收敛为可执行方案；
- 商业化倒推不能牺牲叙事成立性——爽点堆砌不等于好故事。
