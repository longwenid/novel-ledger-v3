# 角色声线与人物鲜活度

人物说话的差别先来自**知道什么、想要什么、面对谁、愿意暴露多少**，才落实为用词、句长、节奏和语气。
同一句话也会因关系、压力和说话者掌握的信息而改变意义。全书所选文风手册管叙述层的共同语感；
角色声线管某个人在特定处境中如何看、如何想、如何开口，两者不可互相代替。

## 1. 稳定底色与可变状态

`plan.character_profiles` 可选，以规范人名为 key，每人保留简短字段：

| 字段 | 记录什么 |
|---|---|
| `background_register` | 经历、职业、社群如何影响其熟悉的事物、称呼与语域；不以身份推定固定口音或智力 |
| `speech_habits` | 可观察的词汇、句式、节奏与回应方式，写倾向而非每句必须出现的口癖 |
| `under_pressure` | 紧张、失势、亲密或说谎时，哪些惯常说法会收紧或变形 |
| `desire_and_mask` | 想从别人那里得到什么，以及对外呈现与心里所想的差距 |
| `sample_quote` | 短语感样句；开书时可拟写，但不算已经发生的事实；后续尽量换成能定位原章的真实台词 |

这些字段可按已有证据填写，未知的留空，不为凑表编造。它们是写作参照，不是对人物的永久判词。
开书时可在 hatch 输入给 `character_profiles`，
也可后来补进 plan；已有小说可从已写正文提炼，不必为了填表重问作者一轮。新增或修改 profile
要与已提交的人物经历、关系和原文相符；旧原句是证据，不要求人物数百章后仍说同一句。

独立的**动态状态**由事件账本与本章章拍承接：人物此时知道或相信什么、误会什么、对谁戒备、
眼前目标如何变化。`state_delta.knowledge` 按 `(who, topic_id)` 留下认知变化；
`knows` 是人物已接受的信息，`believes` 是其相信但未确证的判断，`suspects` 是怀疑，
`refuted` 是其已否定旧说法。它们描述**人物认知**，不把误信写成世界客观事实。
快照只给当前状态，事件保留此前版本；没有记录不证明人物一无所知。

## 2. 让声线在场上工作

编排或写一场对话前，先问：双方分别掌握什么，各自要从对方得到什么，关系允许直说到哪一步？
人物用对话行动：试探、请求、遮掩、压价、安慰、拒绝；停顿、转移话题和反常的直白也能承载潜台词。
再用其经历筛选**会注意到什么、会拿什么作比、会选择哪些词**，而不靠方言拼写、固定口号或
“冷笑”“嘴角一勾”等通用动作辨人。必要时在动作和所选细节中显出反应，不把一切解释成对白。
即使同属一队，每个重要人物也应有自己的局部目标；让其在阻力下作出会留下代价的选择，
而非只轮流说出主角的计划。人物做了什么、没说什么，与说法之间的落差会使其立体。

对话并非每句都要让读者盲认说话者。普通句子可以普通；有辨识度的句子应由立场和情境自然产生。
初次出场可多给可观察的选择与反应，人物建立后不必反复展示招牌语。请区分人物**内心所想**、
对外所说与视角叙述所透露的程度；叙述者知道的真相不能无由变成人物的台词。

角色成长要可追因果：一次失信、胜利或关系改变后，人物可能换称呼、减少命令、敢于直说，
也可能在压力下退回旧习惯。让变化在本场行动和关系中可见，并能从既有事件找到缘由；
不要用一张固定“声音卡”冻结人物，也不要无事件依据地突然换成作者的口吻。

## 3. 按需入包与审稿

- 策划在 `chapters[].present` 写真实在场者；若本章必须用到旧认知，`knowledge_refs` 列其
  `topic_id` 定向召回。认知变化可在对应场 `beats[].effects.knowledge` 写计划结果，正文仍须演出
  谁听见、看见或推断了什么。整张人物档案与知识史不进入写者视图；显式引用在场者的认知超过
  包上限时会停线，须收窄场景或引用，不能悄悄漏掉某个人。
- draft 简报仅给在场者 `character_profiles` 和相关 `knowledge`；polish 仅保留 profile 中可观察的
  语域、句式与受压变化，不带隐藏动机和样句，冻结
  情节与认知；assemble 给在场短档案和相关知识状态核对终稿。档案只提示稳定倾向，不取代已写正文；
  相关话题被省略时，不能把省略当作人物无知，
  应回策划定向补 `knowledge_refs` 或向总编辑报证据不足。
- 事实编辑只从终稿提取本章真正发生的认知变化，沿同一 `(who, topic_id)` 更新并附逐字
  `quote` 与获知渠道 `source`；不能因为读者知道、旁白讲过或作者计划揭晓，就给人物登记 `knows`。
- 抽样审稿：遮去说话标签看主要角色能否凭目标和说法区分；互换两人的关键台词，看是否违背
  其知识与立场；检查是否有人说出未获知的秘密、全员共享作者的机智句式、口癖机械重复，
  以及成长后声线变化是否有事件支撑。样本无法判断时保留疑问，不用自动分数宣称“角色鲜活”。
