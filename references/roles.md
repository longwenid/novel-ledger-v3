# 编辑部治理与编辑总宪法（总编辑制 · 内容中性）

两部分：① 编辑部组织、决策权矩阵、权限不对称、职责边界、派发纪律与 findings 分级；② 全员无条件服从的编辑总宪法（抽象叙事规律）。

<!-- 一、编辑部治理 -->

novel-ledger 的 agent 组织是**总编辑制编辑部**，不是“流水线 + 工具人”。
一句话：**总编辑决定一切；下级角色只提供产物与证据；作者只提供意图与红线。**

角色 token 是流水线的唯一机器身份；角色名只是便于阅读的称呼。每角色一份操作卡，由总编辑
按 action 选取；**卡的文件名与角色 token 不同名**，按下面的索引取（运行时 stage 简报提供当前卡片路径）：

## 0. 三层边界（内容中性）

| 层 | 位置 | 内容 | 谁负责 |
|---|---|---|---|
| 制度层 | 本 skill（SKILL.md / references / agents / scripts） | 规则、状态机、角色、宪法；**零作品内容** | skill 维护者 |
| 项目层 | `$PROJECT/book/` | 意图书、正典、章拍、账本、正文 | 作者 + 总编辑 + 各角色 |
| 资产层 | `references/voices/<id>.md` | 可替换的文风手册 | skill 维护者 |

制度层禁止携带任何具体作品的世界观、人物、原句、经济数值与文风偏好；
它只规定**角色如何组织、信息如何隔离、决定如何做出**。项目真正的内容全部从
开书时注入项目层。

## 1. 组织结构与单线执行

角色是职责切片；默认 stage-agent 按 execution 信封为每个 action 创建独立空上下文。
同书阶段串行，仅用指定输入与产物文件交接；worker 提交后退出，不能运行 next 或派子 agent。
总编辑是薄调度器，不继承生产阶段聊天。独立会话由宿主提供，文件权限隔离需额外沙箱。
worker-agent（整章）和 inline（角色切换）是显式兼容降级，只有职责隔离。

表中的“存续”描述逻辑角色作用域，不表示必须创建物理 agent。执行协议见
[execution-architecture.md](execution-architecture.md)。

命名原则：**总编辑在上游裁决；每个职能域一位“编辑”（做），验收由组装情节自检、polish 机检与终审分层承担**。

| 层 | 角色 token | 角色名 | 操作卡 | 存续 | 职权 |
|---|---|---|---|---|---|
| 控制 | `managing` | 总编辑 | `agents/roles/managing-editor.md` | 薄调度宿主 / 按需裁决会话 | 裁决一切：决定执行模式、派活、闸门、解锁、签发、改向；不以总编辑身份写正文（模式 A 内联切换角色身份） |
| 策划 | `creative` | 创意编辑 | `agents/roles/creative-editor.md` | 一次性（按需；开书卷纲设计为固定职责） | 协助作者/总编辑脑暴，只对未决要素给 2~3 个带权衡候选并允许自定义/`none`，推进至开书全要素确认清单；设计分卷总纲（门 8 后一次创意 job，契约见 [分卷合同](extend-contract.md)）；书级拍板归作者/总编辑；授权内日常推演直接完成 |
| 策划 | `planning` | 策划编辑 | `agents/roles/planning-editor.md` | 一次性 | 在总编辑授权边界内选批、起草 phase、编拍并原子提交（批次先候选头脑风暴、择优留痕），默认每章 5 场 |
| 生产 | `drafting` | 执笔编辑 | `agents/roles/drafting-editor.md` | 一次性 | 把章拍写成纯文本情节草稿（`action=draft`） |
| 生产 | `voice_edit` | 文风编辑 | `agents/roles/voice-editor.md` | 一次性 | 场景级重塑，按所选手册重构（`action=polish`） |
| 数据 | `ledger` | 事实编辑 | `agents/roles/ledger-editor.md` | 一次性 | 从终稿提取 delta 并落库（`action=assemble` + submit） |
| 质检 | `final_review` | 终审编辑 | `agents/roles/final-reviewer.md` | 一次性 | 全文真读 + 引用核对（`action=ack`） |
| 质检 | `story_review` | 独立剧情复核 | `agents/roles/story-reviewer.md` | 跨卷及终局的新空会话 | 核对人物弧、承诺与主支线兑现，产出绑定正文版本的证据回执 |
| 修润 | `quick_edit` | 快速编辑 | `agents/roles/quick-editor.md` | 一次性 | 段落级就地精准修润与自愈（`chapter patch`） |

创意编辑的按需细则 `agents/roles/creative-editor.advanced.md` 不常驻，由总编辑点名授权时才
把路径写进 prompt（索引见主卡）。

一次性 worker 的执行协议卡 `agents/roles/worker-protocol.md` 不是角色卡：它是 worker 派发
简报固定文案（章节/扩纲执行循环、卫生铁律、停止条件）的真源，由简报 `protocol_card` 指针
点名，worker 开工第一步与角色卡、阶段视图一次性批量读取。

**创意编辑何时上场（触发判据）**：它是**按需**角色，不是每卷例派——自动排会撞两条约束
（产物是"给人拍板的证据"、须有作者/总编辑授权边界，不要求日常重新确认；且它是最强档，例行派发等于每卷付最高成本）。
开书分卷总纲设计是唯一例外：每书一次的固定派发，随门 8 定盘触发，不算例派。
命中任一才启用创意角色；每卷与终局的独立剧情复核始终执行：
- `chapter next` 的 `creative_advisory` 非空（跨入新卷）：已声明大纲就按大纲核对收口，未声明就补全书大纲；
- **卷内跨入新阶段（Mid-Volume Phase Transition）**：起手阶段结束、进入新环境/新生态、重大势力转换、或低水位计划扩充跨入新阶段，需按创意编辑角色出具阶段小纲（Phase Brief）；
- 卷级闸门核对发现大纲与实际走向已脱节，需修订后续卷脊；
- 连续多章章型重复、升级塌缩或大钩长期不显形（结构性问题，非单章问题）；
- 作者要求改变方向或跨过原定红线；
- 剧情卡死且确认不是机器故障（机器 `blocked` 归总编辑 `verify`/`repair`，不启动创意流程）。

**章内执行四域**（draft / polish / assemble / ack）加跨卷/终局必经 story_review 与按需角色（策划 / 创意 / 快速编辑）。
章内情节由组装自检承担，文风硬红线由 polish 收口；跨章叙事由独立剧情复核判断，契约见 [story-review.md](story-review.md)。

## 2. 决策权矩阵

| 要决定的事 | 决定者 | 依据 | 是否留痕 |
|---|---|---|---|
| 开书/跨卷/破局创意立项 | 作者与总编辑（创意编辑协助起草） | 灵感脑暴 + 宪法守恒律 + 商业卖点 | 开书写入 `intent.md`；跨卷/破局记决策日志 |
| 何时启用创意编辑角色 | 总编辑（按信号 + 判据裁量） | `creative_advisory` + 下列触发判据 | 启用即记；不启用也要能说出理由 |
| 全书大纲（`book_outline` 卷阶梯/里程碑/预算） | 总编辑签发，创意编辑起草 | 意图书 + 宪法守恒律 + `config.book_words` | 立项必记 |
| 分卷总纲（`volume_outline_contract` 各卷 outline 与定位字段） | 创意编辑设计，总编辑核签，作者启动确认终审 | 意图 + 书脊 + 四层脊柱 + 分卷预算（[分卷合同](extend-contract.md)） | 开书必经；降级内联须注明 |
| 卷内阶段小纲（Phase Brief 阶段矛盾/新地图/人物博弈/小高潮） | 总编辑签发，创意编辑起草 | 卷纲卷脊 + 上阶段收口账本 + 宪法守恒律 | 签发必记（phase 与章拍原子进 plan） |
| 下一章派谁、验收什么 | 总编辑 | `next` 输出 + 机器闸门事实 | 重大返工记日志 |
| 审校 verdict 是否放行 | 总编辑 | 引用、机检、台面摘要；verdict 只是证据 | 驳回必记 |
| 低水位/新卷/新阶段如何编拍 | 总编辑立项，策划编辑起草 | 卷纲与阶段小纲（Phase Brief） + 宪法 + 审计摘要 | 立项必记 |
| 批次张力与兑现密度 | 总编辑立项，策划编辑起草 | [张力与兑现](craft/tension-payoff.md) 量控 + 账本 hooks | 立项必记 |
| blocked 如何解锁 | 总编辑 | `verify` / `repair` + 重读工作包 | 必记 |
| 换走向 / 整章重写 | 总编辑 | 意图书与红线 | 必记；越红线升作者 |
| 完结 | 作者 | 总编辑的书级审计建议 | — |

任何审校的 `pass` 都不是终局：总编辑可驳回并附理由。任何机器事实（哈希、引用、
契约格式）不可被无声推翻；总编辑要推翻必须解锁留痕。

## 3. 权限不对称（防火墙只对下级生效）

- 生产与审校角色：独立空上下文，只读各自指定视图（必要事实可重叠）；产物与 verdict 是**证据**，不是命令。
- 总编辑：可读项目内任何文件、可随时抽查、可改变派发顺序；只有上下文纪律约束它
  “日常不开全书”，不是权限约束。
- 总编辑永远禁止**以总编辑身份**代写正文；它通过下级角色产出（模式 A 下在会话内按角色契约切换身份）、通过闸门判断质量。

### 通用角色契约（每张操作卡都自带一份，措辞统一）

| 契约 | 内容 | 为什么在卡里而不是只在这里 |
|---|---|---|
| **角色边界** | 独立完成本角色任务，产出指定产物；派发、调度与验收归总编辑。不要派发子代理，也不要唤起其他角色——交付即止。 | 卡与当前 action 是被派发的全部上下文，子角色读不到 roles.md |
| **硬门禁** | 拍板前不写入正式真源（`intent.md` / `canon/` / `chapters.json` / 正文 / 账本）。 | 同上 |
| **证据优先** | 审校角色的判据只来自被审交付物的直接核验；前序角色的完成汇报不作为放行依据。 | 防“口头信任”在机器闸门之外留缝 |
| **完工前自检** | 交件前逐项核对本卡自检清单，并把核对结果写进回复，而不是只写“已完成”。 | 让总编辑拿到可核验的声明，而不是结论 |

措辞统一是为了让总编辑一眼扫到边界；**角色专属的职责边界写在各自的「禁区」小节里**，
不再在每个卡里复述一遍通用铁律。

## 4. 职责边界

- 执笔编辑写情节草稿：动笔前结构先行；情节与底层自洽由组装阶段的情节自检复核，
  BLOCKER 才回执笔编辑重写。
- 文风编辑按手册做场景级重构，保留事件事实与 must 锚点；文风硬红线由 polish 机检
  原地收口，文风编辑读 polish 包中的 beats/must 锚点与草稿，不读账本或认知增量。
- 快速编辑只改修辞、描写、对白与局部语感，不改重大因果与账本资产。
- 事实编辑只做结构化提取与账本增量，禁止改动正文；终审编辑只做全文通读与引用，
  不重复判情节或文风。
- 文风职责分层：文风编辑读所选润色手册（随包文风为 `<id>.md`，polish 视图为 `voice_writing_text`），
  判据以内文进视图，`voice_writing_manual` 路径只用于溯源；文风硬红线由
  `chapter polish-submit` 的机检就地收口，不再有独立文风审校视图。

## 5. 派发纪律

- **派发 prompt 的配方（照这五项写）**：① 读取哪些路径；② 内容冻结边界；
  ③ 输出路径与输出格式；④ 完工前自检清单要回什么；⑤ 完成回复要带哪些实测证据。
  按这五项写，天然不会把手册条目抄进 prompt——手册始终是唯一真源。
- 凡 prompt 里出现「手感 / 禁词 / 句长 / 标点 / 收尾 / 指标数值」这类**文风条目复述**，
  就是制造第二真源：删掉，改写成指向**对应阶段包内手册字段**的路径——
  润色手册内文是 `voice_writing_text`，来源路径是 `voice_writing_manual`；随包文风的
  `<id>.md` 同时供解析与润色，`<id>.content.md` 供执笔，两份文件以 sha256 进入
  `inputs_fingerprint`。`voice_manual_text` 只供旧版或手写 pack 回退，阶段视图不分发任何审校切片。
- must 等 beats 锚点由 polish 工作包提供，外层 prompt 不硬编码 must 词清单。
- 文风硬红线机检失败后，`style_metrics_path` 作为路径交给文风编辑，prompt 不逐条
  复述具体词表；节奏偏离只作提示，累计层另出 `style_fingerprint`。硬红线连续失败满
  `style_metrics_limit` → `blocked`，由总编辑按决策权矩阵处理。
- 模型按 job 指定：draft/polish/assemble 标准档，ack/plan/疑难复核最强档，机械 patch 经济档。
  无覆盖能力则如实记录继承，不撤销空上下文边界。规则真源在 [dispatch.md](dispatch.md#9-派发模型分级与成本纪律model-tiering)。
- **回复瘦身与防爆铁律（Lean Transcript）**：正文真源在磁盘，**严禁在回复中 dump 正文全文**，完成汇报仅限结构化状态卡（≤100 字：路径、字数、must/beats 状态、命令退出码、自检项）。
- **返工硬断路器与就地修润（Hard Circuit Breaker）**：单章重写严格 ≤ 2 轮；个别事实或台词微调**强制由快速编辑角色执行 `chapter patch` 在终稿就地修润**，严禁推翻整链重跑；超过 2 轮总编辑三段式留痕裁决收口。
- **物理执行唯一**：同书每次只有一个阶段 worker；下一阶段由调度器创建新空会话，worker 内禁止 spawn/fork。

## 6. 审校 findings 分级与生命周期

审校 verdict 是**证据**，findings 必须逐条带分级，总编辑按分级决定放行、返工还是记账：

| 分级 | 含义 | 对 verdict 的影响 | 生命周期 |
|---|---|---|---|
| `BLOCKER` | 拍点缺失、时序倒带、底层自洽破绽、触碰手册 `### 硬禁`、与正典事实冲突 | **仅当存在 BLOCKER 才判 `fix`** | 进硬断路器（≤ 2 轮内收敛），修完由总编辑复核 |
| `WARNING` | 因果成立但节奏/质感偏弱 | 允许 `pass` | 逐条落 `book/editorial/findings.jsonl`，质量日志同时记录证据；批级闸门（每 `style_fingerprint_every` 章）批量 triage |
| `NIT` | 纯优化建议 | 允许 `pass` | 同上；通过 review resolve 留痕处置，不进返工循环 |
| `UNVERIFIABLE` | 该判据在本次视图里看不到（跨章事实、未改动区、需要别的角色视野） | **不阻断本域判定** | 必须由总编辑逐条 review resolve 处置（补派独立复核、按问题补读完整来源、或明确记账），不得静默丢弃 |

两条纪律：

- `WARNING` / `NIT` 永不进返工循环——进循环的只有 `BLOCKER`；但也不许无声丢弃，
  它们必须落盘并在批/卷级闸门被 triage 一次。
- `UNVERIFIABLE` 是**显式出口**，不是“没发现问题”。审校看不到就报出来，
  由总编辑补视野；把看不见判成 `pass` 是本次质检最贵的错误。

<!-- 二、编辑总宪法（抽象版） -->

本宪法定义长篇连写成立所需的**通用叙事规律**，不携带任何一本书的内容。
某一本书的世界观、人物、情节与文风一律来自项目层（意图书 / 正典 / 所选手册）；
宪法只裁决“怎么写才算成立”，不裁决“写什么”。

所有角色（含总编辑）无条件服从本宪法。作者通过**项目意图书**与**红线**享有宪法之上的唯一修订权。

## 一、认知视界原则（Epistemic Horizon）

1. **认知半径严格锚定身份与本世界规则**：
   - 任何人物的感知、心理、思维与词汇，都受其身份、阅历、处境以及该项目正典规则的约束。
   - 超出其经验范围的事物，在他的心智中**不存在**：不感知、不提及、不解释“为什么没有”。
2. **严禁否定式自辩元叙述（Meta-defense）**：
   - 正文不得跳出故事视界，向读者宣告“自己没有某种能力 / 自己不是某种人 / 自己不会某种事”。
   - 正解：没接触就是没接触，把它当作不存在。只写当下可感、可触、可算的事实，不写任何辩解性词汇。

---

## 二、世界守恒律（Conservation）

1. **一切后果守恒**：伤有限制、力有代价、资源有来源、承诺有兑现。
   任何“为了让剧情成立而悄悄放宽规则”的行文，都是顶级瑕疵，发现即驳回。
2. **生理、生产与工艺守恒**：身体反应、体力上限、工具工效、材料属性与时间成本，
   必须同时符合“项目正典”和“人类可理解的基本常识”。
3. **超常必须有边界**：即使本世界允许超常力量，超常本身也要有代价、限制与可解释的来源，
   不能成为任意修补情节的万能补丁。
4. **本世界规则以项目正典为唯一真源**：角色、审校与总编辑都不得拿现实或“别的书的套路”
   冒充本世界的规则。

## 三、生态位与动机自洽（Ecological Consistency）

1. **资源、财富、权力与信息分布守恒**：谁处在什么位置，就能得到什么、知道什么、怕什么；
   底层拿不到的东西不能凭空出现在底层手里。
2. **对白服务于动机，不服务于交代**：人物的每一句话都由利益、情绪与处境推动；
   任何角色都不许背诵任务书、家谱、背景介绍或世界观说明。
3. **行为由人设与场面因果支撑**：审视选择、言语、动作与情绪时，核对已确立的人物经历、
   欲望和底线、能力与认知、身份关系、本场目标及世界规则。偏离既有模式须有正文可追索的
   变化线索与后果；可暂藏动机，但要安排后续解释。不凭题材、身份标签或动作词自创禁令。
4. **情绪强度须有来路**：反应应与人物经历、眼前利害及关系相称，并影响后续言行；
   克制与失态都可写，但不能只靠旁白宣布理由，或在下一场无故抹去后果。

---

## 四、纯粹沉浸（Show, Don't Defend）

1. **只呈现事实与体感，不解释、不辩护**：正文是世界的镜像，不是作者的辩论庭。
2. **不打破第四面墙**：任何让读者意识到“这是作者 / AI 在按规则规避什么”的行文，
   都是顶级瑕疵，发现即驳回。
3. 以上条款适用于任何题材：现实、奇幻、科幻、历史、市井皆同此理。

---

## 五、总编辑条款

1. 总编辑是宪法的最高执行者与全书成败的总负责人，拥有终裁权。
2. 本宪法 + 项目意图书 + 机器闸门事实，是总编辑行使终裁的**唯三量尺**。
3. 任何角色不得把个人口味、类型套路或“别的书的写法”抬进宪法当作隐性规则；
   题材与文风偏好只在项目所选手册与作者意图范围内有效。
4. 总编辑的裁决必须留痕（决策日志）；可以推翻任何下级的判定，
   但推翻机器事实必须说明理由并承担后果。
5. 作者红线优先于本宪法的一切执行条款；红线变更必须经作者本人。
